EPYC platform eras

What changed Naples → Rome → Milan for the metal, board, cooler, PSU, and dual-socket rack?

Chassis thesis: all three gens share socket SP3. Used 1U/2U Supermicro SP3 chassis stay useful across three CPU gens when the board BIOS supports the part. Rome→Milan is usually a CPU upgrade; Naples→Rome is the bigger platform jump.
Same socket SP3Naples · Rome · Milan = LGA 4094. One reason used SP3 racks keep working.
Naples → RomeBigger jump: PCIe 3.0→4.0, Zeppelin MCM → IOD+CCD, DDR4-2666/2 TB → DDR4-3200/4 TB class.
Rome → MilanSame platform plate: better Zen 3 cores/cache/IPC on the same board/cooler class (BIOS update).
After MilanGenoa (9004) breaks to SP5 + DDR5 + PCIe 5.0. Different boards/coolers. Footnote only.

Chassis implications implied + sourced cooler dims

Cooler height (SP3)

Arctic Freezer 4U SP3: 152 mm H, marketed for 4U, 300 W claim. Supermicro SNK-P0064AP4: 4U active, up to 280 W. AMD SP3 thermal guide reference heatsink mass <450 g (OEM 1U/2U). Tall tower coolers used in homelab may exceed that mass. direct

Board form

SP3 server boards are commonly EEB / proprietary. Dual-socket boards need two coolers and depth for DIMM banks + airflow. Same metal class for Rome and Milan. implied

1U thermal pain

Short-depth 1U + high-TDP EPYC (Milan to 280 W) forces small high-RPM fans. Living-space noise risk matches the Form-factor 1U notes (Uniqcli / Hardwarehoard / Level1). Prefer 2U/4U for room-adjacent hosts. implied

Used BIOS caveats

Socket continuity ≠ automatic CPU support. Example: Supermicro H12SSL-i listed Rome/Milan, not Naples. ASRock Rack ROMED8-2T cited as multi-gen with BIOS updates. Verify AGESA/BIOS before buying used SP3 boards for Milan. implied

PSU / 2P

Non-P SKUs support 2P on all three gens; 2P spends 64 of 128 PCIe lanes on Infinity Fabric. System watts left unknown (not invented). Size PSU for CPU TDP + drives + NIC/GPU headroom. direct 2P · unknown system W

Milan-X footnote

Milan-X (e.g. 7773X) adds 3D V-Cache on the Milan SP3 / DDR4 / PCIe 4.0 plate. Same chassis/board class; watch TDP (280 W on top SKUs). direct

Interpretation labeled interpretation

Naples · cheap entry

Tray asks can be tens of dollars (China New 7401P $22) to low hundreds (US Dell-pull 7351P ~$300). Buys Zen 1 / PCIe 3.0 on SP3 metal. Check board BIOS if you hoped to climb to Milan later.

Rome · sweet spot PCIe 4

Mid P-skus (7302P/7402P) cluster roughly $67–$375 today. Same cooler/board class as Milan on many H12 boards, with PCIe 4.0. 7742 jumps to ~$500–$700 for 64 cores.

Milan · premium same SP3

Mid Milan asks ~$555–$1100. You pay for Zen 3 cores/cache/IPC on the same SP3 chassis plate, not a new socket. H12 / ROMED8-class BIOS required; H11 Naples boards often will not boot Milan.

Boards / systems

Used H11SSL-i ~$456; New H12SSL-i ask ~$850. Complete 1U systems (e.g. R6415+7351P ~$1181) are labeled system, not CPU. BIOS caveat beats a cheap CPU.
