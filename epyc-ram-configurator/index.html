Why 8×64 only

DIY ATX boards (ROMED8-2T, H12SSL-i) expose 8 DIMM slots. 8×32 = 256 GB. Hitting 512 GB on these boards means denser sticks: 8×64.

Path C · Dual-socket step-up (optional)

7402P is single-socket only. Dual-socket needs 7402 (non-P) ×2. Swapping a 7402P into a dual board will not enable the second socket.

Separate from Path B. Dual needs 7402 (non-P) ×2 — 7402P is single-socket only. Board e.g. H12DSi-N6 / H11DSi. More memory channels; not required just to run 16×32.
